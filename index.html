Core Features

Deploy

服务器端部署_

一台常开的 Linux 机器（1 核 1 GB 起，2 核 896 MB 实测够用）+ 一块 AI Passport，就能跑起来。

user@server: ~/ai-passport-bili
# 1. 拉取仓库
$ git clone https://github.com/qfmy78/ai-passport-bili.git
$ cd ai-passport-bili

# 2. 一键装环境：Python 3.11 + ffmpeg + venv + systemd
#    过程中会交互式收集 B 站 Cookie 和配对码
$ sudo bash deploy/install.sh

# 3. 取配对码，等下填进设备的配网页
$ sudo bash deploy/install.sh --show-pairing

# 4. 自检：登录状态、已配对数
$ curl -s localhost:10745/api/health

# 5. 跟日志（播放出问题时先看这里）
$ journalctl -u passport-bili -f
$

配置文件在 /etc/passport-bili/env（权限 600），至少要填 BILI_SESSDATA； 控制端口 10745、媒体端口 10746 记得放行。设备上电后连热点 PassportTV-xxxx → 打开 192.168.4.1 → 填服务器地址、端口和配对码。 固件需要 ESP-IDF v5.5，用 ./tools/build.sh 与 ./tools/flash.sh COM8 编译烧录。
